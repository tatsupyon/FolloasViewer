FolloasConverter (データコンバータ) システム仕様書

1. システム概要

本システムは、AI認識ログと複数系統のライブ映像を統合し、Viewerでの高速な可視化を可能にするためのデータ最適化ツールです。 最新バージョン: V1.36 (2026/09/13)

2. 動作環境・依存ライブラリ

  • Pythonバージョン: Python 3.14.4
  • 標準ライブラリ: os, csv, re, tkinter, threading, tempfile, shutil, contextlib
  • 外部ライブラリ:
  • opencv-python (cv2): 映像のデコード、フレーム抽出（静止画化）
  • numpy: 画像配列のメモリ管理

3. 主要な内部ロジック

  • ログ同期の堅牢化 (Dropout Resilience):
  • ログファイルから抽出される時刻（timestamp）が連続していない場合、基準となる 30fps のインターバル（33.33ms）に基づいて「空の認識結果」を自動挿入します。
  • これにより、ネットワークの遅延やAICPUの処理落ちでログが欠損しても、Viewer側のタイムラインとの同期が壊れないように設計されています。
  • CSVパーサーの適応性:
  • AI出力ログの第1行目がヘッダー（文字列）か実データ（数値）かを正規表現で自動判定。
  • ヘッダーの有無に関わらず、Frame 0 からの全データを正確に抽出します。
  • フレーム抽出の最適化:
  • live1 (基準30fps) は1フレームずつ全て抽出。
  • live2 (25fps) は OpenCV のシーク機能を利用し、基準タイムラインに最も近いフレームを近似的に同期して抽出。
  • 日本語パス・非ASCII文字への対応:
  • _video_capture_context を通じて、一時的なシンボリックファイルまたはコピーを作成し、OpenCV が日本語パスを直接扱えない制限を回避しています。
  • 特殊TSファイル(0x00A0)への堅牢な対応:
  • 標準のFFmpegデマクサで解析不能なMJPEG-TSファイルに対し、188バイトのTSパケットヘッダーをバイナリレベルで機械的に除去する _strip_ts_payload ロジックを搭載。純粋なMJPEGストリームを再構成して抽出を可能にします。
  • サイレント・バッチ処理最適化:
  • subprocess.CREATE_NO_WINDOW フラグの使用により、FFmpeg実行時のコンソールポップアップを完全に抑制。
  • 引数指定起動（バッチモード）時は、エラー時を含めポップアップを一切出さず、ターミナルへのログ出力と自動終了を行う完全自動運転仕様。
  • プログレスバーの同期精度:
  • バイナリ修復時にJPEG開始マーカー（FF D8）を直接カウントすることで、正確な総フレーム数を把握し、GUIの進捗表示と100%同期させます。

4. 出力データ仕様 (_ViewReady フォルダ)

  • live1/*.jpg: 30fpsの基準連番画像
  • live2/*.jpg: Live1に同期された連番画像
  • sync_log.csv: 各フレームに対応する認識結果を1行に集約
  • 形式: FrameIndex, TimeStamp, score1, x1, y1, w1, h1, s1, ...
  • meta_info_panel.png: 画面キャプチャから抽出した装置・設定情報（Viewer表示用）
