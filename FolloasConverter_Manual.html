Folloas データコンバータ 操作マニュアル

対応バージョン: V1.36〜 動作環境: Python 3.14.4

1. はじめに

本ツールは、録画された重い動画ファイル（TSやMKV）と認識ログデータを、Viewerで高速にシーク・同期再生させるための「連番静止画データ（_ViewReady）」に事前変換するツールです。

2. 操作手順

  1. ツールの起動: FolloasConverter.py または FolloasConverter.exe を起動します。
  2. 起動時に引数 -rotate を指定すると、後述の「180度回転」オプションが最初からONになります。
  3. 対象の選択: 「処理対象フォルダ」の [参照] ボタンをクリックし、録画データが入っているフォルダを選択します。
  4. フォルダ内には *_vlc_record_live1.ts, *_vlc_record_live2.ts, *_screen_capture.mkv, *_head.log の4点が揃っている必要があります。
  5. 変換の実行: [変換開始] ボタンをクリックします。
  6. [180度回転] チェックボックスをONにすると、生成される画像とAIの認識枠座標が180度反転して出力されます（カメラ逆さ設置時に使用）。
  7. プログレスバーが進行し、現在の処理フェーズが表示されます。
  8. 日本語フォルダ名や全角文字を含むパスも問題なく処理できます。
  9. 完了確認: 「変換完了！」というメッセージが表示されたら完了です。
  10. 元のフォルダと同じ場所に 「元のフォルダ名_ViewReady」 というフォルダが作成されます。このフォルダを FolloasViewer で開いてください。

3. バッチ処理（一括変換）

複数のフォルダをまとめて変換したい場合は、バッチファイル（.bat）を利用できます。 * コマンド例: python FolloasConverter.py "C:\path\to\folder" -rotate * バッチモードで起動した場合、以下の通り動作が自動化されます。 * 起動後のポップアップ通知なし（すべて自動で開始）。 * FFmpegの黒い画面（ウィンドウ）は一切表示されません（背後で静かに動作）。 * 完了後、自動的にウィンドウを閉じて終了します。 * エラーが発生した場合も、ポップアップで止まらずにターミナルへログを残して次の処理へ進みます。

4. 高度な機能と注意点

  • データの整合性維持:
    • 万が一ログデータが途中で途切れていても、時間を理論値（30fps一定レート）で補完しながら変換を継続します。
  • 特殊なTS動画への自動対応:
    • 一部のカメラやVLC録画で生成される、標準プレイヤーで再生困難なTSファイル（コーデック 0x00A0 等）も、内部で自動修復して変換します。VLCでの事前変換作業は不要です。
  • 最新ログ形式への対応:
    • AIが出力するログにヘッダー行がない場合でも、自動的にデータを判別して変換を行います。
  • 中断（キャンセル）:
    • 処理中に [キャンセル] を押すと安全に終了します。
